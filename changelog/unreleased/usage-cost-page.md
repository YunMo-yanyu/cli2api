### English

- Add a **Token usage** console page reporting the tokens and subscription quota consumed through cli2api, per model. Quota applies to every provider, so the breakdown covers WorkBuddy, Qoder, Trae, and the other adapters even when a model has no official list price. DeepSeek usage is additionally converted into an equivalent cost at the official list price, split into peak and off-peak hours (estimated using Beijing time Monday–Friday 09:00–12:00 and 14:00–18:00 at double the off-peak rate; holidays and adjusted working days are not handled). The page shows a quota card, the equivalent cost card, a stacked cost-over-time chart, a per-model table (requests, cache-hit / cache-miss input, output, tokens, peak vs off-peak cost, quota), and the official price table. Usage is attributed to the actual mapped model, falling back to the requested name for older logs. Data covers retained request logs only; retention is configurable with CLI2API_LOG_RETENTION_DAYS and CLI2API_LOG_MAX_ROWS (defaults: 7 days / 20,000 rows).

### 中文

- 新增控制台「Token 用量」页面，按模型统计经 cli2api 消耗的 token 与订阅额度。额度对所有 provider 都成立，因此即使某个模型没有官方列表价，明细里依然会列出 WorkBuddy、Qoder、Trae 等各适配器的用量。DeepSeek 的用量还会按官方列表价折算出等效费用，并区分高峰与闲时（按北京时间周一至周五 09:00–12:00、14:00–18:00 估算为闲时的两倍；未处理节假日及调休）。页面包含额度卡片、折合费用卡片、按模型堆叠的费用趋势图、按模型明细（请求数、缓存命中/未命中的输入、输出、token 总量、高峰与闲时费用、额度）以及官方价格表。用量优先归入实际映射模型，旧日志缺少映射时回退到请求名称。数据仅覆盖留存日志，可通过 CLI2API_LOG_RETENTION_DAYS 和 CLI2API_LOG_MAX_ROWS 配置留存（默认 7 天 / 20,000 行）。
